# Results Dashboard

React + Vite dashboard that visualizes the classical DQN vs quantum DQN comparison: accuracy and F1, training loss, and the IBM Quantum jobs used in the run.

```bash
npm install
npm run dev
```

Built with React 19, Recharts, Framer Motion and Tailwind CSS. Data comes from the run described in [`../RESULTS.md`](../RESULTS.md).
